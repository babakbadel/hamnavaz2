# AI Operations: Graphy + Headroom + Logging

## Graphy
Track project entities, dependencies, decisions, APIs, data flows, and relationships as a connected graph.

## Headroom
Keep context, prompts, tool output, and artifacts compact and structured while preserving critical project state.

## Logging
Record significant development actions, deployments, tests, errors, and architectural decisions. Never log secrets, tokens, credentials, or personal data.

Use Git commits, PRs, issues, and project documentation as the durable project history.
